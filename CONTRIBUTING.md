# Contribuir a VoxTexto

Usa Node.js 24, instala con `npm ci` y trabaja en una rama propia.
Antes de proponer cambios ejecuta `npm test` y `npm run build`.
Para cambios de interfaz ejecuta también las pruebas Playwright con Chrome disponible.

Describe el problema, los cambios y las pruebas realizadas en tu pull request.
No adjuntes grabaciones privadas, transcripciones reales, credenciales, modelos,
dependencias instaladas ni archivos generados. Usa ejemplos ficticios o audios públicos
con una licencia compatible. Conserva la licencia MIT y los avisos de terceros.

La detección y la inferencia se prueban por separado de la edición demostrativa.
Una prueba del ejemplo no acredita la calidad del reconocimiento de voz.
