# Revisión para publicación

Revisión realizada el 21 de octubre de 2026 sobre el ZIP recibido de VoxTexto 0.3.0.

## Alcance

Se inspeccionaron rutas del ZIP, tamaños, archivos de configuración, código de audio,
inferencia, exportación, interfaz, scripts y documentación. No se ejecutaron los
binarios ni las dependencias incluidas en el ZIP. Las dependencias de comprobación
se instalaron desde npm con el archivo de bloqueo y scripts de instalación desactivados.

El ZIP contiene 12 689 entradas y 717 278 404 bytes descomprimidos. No se encontraron
rutas con traversal ni enlaces simbólicos. La selección pública excluye node_modules,
build, dist, target, cachés, temporales, grabaciones y capturas no necesarias. Se conserva
solo una captura de interfaz sin audio ni transcripciones privadas, identificada como 0.2.0.
El análisis de patrones de credenciales no encontró coincidencias en la selección de código;
esto no equivale a una garantía absoluta de ausencia de secretos.

## Arquitectura verificada en el código

- React 19 y TypeScript, compilación con Vite 7. Archivo de bloqueo incluido.
- Whisper Base ONNX mediante Transformers.js 4.3.1, ejecutado en Web Worker.
- Selección WebGPU con alternativa WASM/CPU; modelo descargado externamente.
- Web Audio API para decodificar y mezclar a mono de 16 kHz.
- Detección automática del idioma a partir del audio y selección manual.
- Edición por segmentos con marcas temporales; exportaciones TXT, DOCX y PDF.
- Manifiesto y service worker para instalación y caché de interfaz.
- Sitio estático público generado para / y editor en /app/.
- Tauri 2 y código Rust como contenedor de escritorio, sin instalador probado en esta revisión.

## Comprobaciones de esta revisión

- 13 pruebas unitarias aprobadas en tres archivos.
- Compilación TypeScript y build para /app/ aprobados.
- Verificación del sitio: 10 HTML y 8 URLs en sitemap, recursos locales presentes.
- npm audit --omit=dev: cero vulnerabilidades reportadas al ejecutar la revisión.
- Cuatro flujos Playwright aprobados: edición del ejemplo con generación de TXT/DOCX/PDF,
  metadatos reales en el límite de una hora, cancelación y ayuda en pantalla móvil.
- La prueba de PDF multilingüe falló con «Execution context was destroyed» al evaluar
  la página. No queda validada en esta revisión. La prueba opcional de voz real se omitió.
  El proceso de pruebas no terminó tras ese fallo y se interrumpió; no se declara la suite completa aprobada.

Vite avisa de archivos JavaScript grandes y de theme.js como script clásico.
El build termina correctamente. El motor WASM generado ronda 26,9 MB y los pesos
pueden sumar cientos de MB: no se incluyen en el repositorio.

Se excluyen iconos nativos de plataformas no configuradas y sus variantes sin uso;
se conserva icon.ico, referenciado por el empaquetador Windows, y los cuatro iconos PWA.

## Límites para presentar el proyecto

Esta revisión no ejecuta reconocimiento con voz real ni evalúa precisión o rendimiento
en una matriz de dispositivos. Los informes previos permanecen como antecedentes
con su fecha. No se acredita una transcripción completa de una hora ni instalación
en teléfonos físicos. Los 60 minutos y 100 MiB son límites de admisión del código.

El código de la app no tiene un servidor receptor de audio; descargar el modelo sí
contacta a proveedores externos. No hay traducción, resumen, diarización ni bot de reuniones.
La aplicación pierde la sesión al cerrar si no se exporta el texto. Algunos PDF
multilingües se generan como imágenes y no conservan texto seleccionable.

## Publicación

Se conserva MIT y THIRD_PARTY_NOTICES.md. El dominio configurado es voztexto.com,
distinto del nombre de marca VoxTexto; no se presenta como sitio desplegado ni se
compra o cambia DNS. El repositorio de código no equivale a un servicio web publicado.
